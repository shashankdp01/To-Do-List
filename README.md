📝 To-Do List Web App

A simple and responsive To-Do List application built using HTML, CSS, and JavaScript. This app helps users add, delete, and manage daily tasks efficiently with a clean user interface.

🚀 Features

➕ Add Tasks – Quickly add new tasks to your list

✔️ Mark as Completed – Toggle tasks as complete/incomplete

🗑️ Delete Tasks – Remove tasks with a single click

💾 Local Storage Support – Tasks are saved even after refreshing the page

📱 Fully Responsive UI – Works on desktops, tablets, and smartphones

🎨 Clean & Modern Design – Neat layout with simple interactions

🛠️ Tech Stack

HTML5 – Structure of the app

CSS3 – Styling and layout

JavaScript (Vanilla JS) – Functionality and DOM manipulation
